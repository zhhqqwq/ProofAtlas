## Route stability is semantic, not textual

Examples:

- Sequence-limit uniqueness uses `max{N1,N2}`.
- Function-limit uniqueness uses `min{δ1,δ2}`.

The merge operator changes because the quantifier interface changes, while the common-approximant bridge stays invariant.

Likewise:

- limsup subsequence construction needs recursive index compatibility;
- a static `sup A` witness sequence does not.

The isomorphic case legitimately removes the recursive-index policy while preserving the near-extremal-witness mechanism.

## Main result of pair design

The v0.1 Pattern Library remains structurally adequate for the 18 selected anchors.

The new pressure is evaluative rather than ontological:

- detect mechanism invariance;
- distinguish harmless surface change from real route change;
- calibrate constants under perturbation;
- preserve witness origin;
- test theorem-interface transfer.

No new CPG core object family is required.
