# Pattern Library v0.2 — Stability Report

The 18 perturbation/isomorphic pairs do not justify another broad pattern expansion.

## Stress-tested v0.1 mechanisms

- Bridge / Intermediate Object
- Localization / Local Stabilization
- Error Budget Allocation
- Constraint Merge by min/max
- Tail Control + Finite Prefix
- Compactness Extraction
- Recursive Selection Policy
- Near-Extremal Witness
- Bad Object / Bad Sequence from Negation
- Theorem-Input Manufacturing
- Domination / Scalarization
- Representation Alignment / Residualization
- Anchor Condition

## New rule: mechanism signature

A transferable pattern should be represented by:

```text
trigger / obstacle
→ required property
→ operation
→ returned artifact or control guarantee
```

A pattern has not transferred merely because its English label still sounds applicable.

## Not promoted to new patterns

The following remain subcases of existing mechanisms:

- changing `1` to `2`;
- changing `1/2` to `1/3`;
- changing `1/n` to `2^-n`;
- alternate legal bridges;
- safe fractions such as `d/2` vs `d/3`;
- base-2 vs base-3 geometric blocking.

A new pattern should require repeated hidden/external failures that existing mechanisms cannot describe without distortion.
