# Analysis examples

This directory will hold worked examples demonstrating the difference between:

- a polished reference proof;
- a ProofAtlas proof map;
- Motivation Fidelity reconstruction;
- Construction Archaeology;
- theorem-role analysis;
- constant provenance;
- learner-adaptive explanation.

Examples are intentionally deferred until the prototype skill is run on real material, so that the repository does not present hand-written demos as if they were validated system outputs.
